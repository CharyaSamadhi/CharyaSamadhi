## 🚀 Featured Projects

### 🏪 Bike Sales Data Warehouse & Power BI Dashboard
> *Enterprise-scale BI solution built from the ground up*

Implemented a **star-schema data warehouse** in SQL Server for 100,000+ bike sales records spanning time, product, customer, and geography dimensions. Designed and deployed **SSIS ETL workflows** for data cleansing, fact/dimension loading, and accumulating fact updates. Delivered interactive **Power BI dashboards** revealing revenue trends, profit margins, and regional sales performance.

`SSMS` `Power BI` `SSIS` `SSAS` `SQL Server` `ETL` `Visual Studio`

---

### 🧬 Employee Attrition Prediction System
> *Predicting turnover before it costs the business*

Built an end-to-end **ML prediction system** on a 100,000+ row HR dataset. Applied comprehensive data preprocessing, exploratory data analysis, feature engineering, and **SMOTE** to resolve class imbalance. Trained and tuned classification models, then deployed the final solution as a real-time **Streamlit web application**.

`Python` `Pandas` `Scikit-learn` `SMOTE` `Streamlit` `EDA` `Feature Engineering`

---

### 🎬 Movie Night Planner — Multi-Agent System
> *AI-powered recommendation engine with agent orchestration*

Architected a **multi-agent movie recommendation system** that intelligently processes user preferences, fetches live data, and generates structured recommendation pipelines. Built **FastAPI** microservices for agent communication and data processing, integrated external APIs (Hugging Face, TMDB), and delivered a seamless **React frontend** experience.

`Python` `FastAPI` `React` `SQLite` `JWT` `Hugging Face` `TMDB API`

---

### 🌍 Online Tour Booking System
> *Full-stack booking platform with real-time CRUD*

Developed a production-ready **MERN-stack** web application supporting full CRUD operations, secure user authentication via **JWT**, and a dynamic React frontend for browsing and booking tour packages. Implemented RESTful API architecture for scalable data exchange.

`MongoDB` `Express.js` `React.js` `Node.js` `JWT` `REST API`
